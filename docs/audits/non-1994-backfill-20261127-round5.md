# 1992年全区投票统计交叉核验

原整届统计采用第三方汇编：13,421,170 / 9,666,020 / 9,489,305 / 176,715。
现依据官方2020年统计年鉴表93（原始来源中选会）选举人数13,421,170、投票人数9,666,021；政大保存的中选会1992年政党得票统计表有效票9,488,772；无效票由相减得到177,249。分票种统计如下（选举人数、投票人数、有效票、无效票）：

- 区域：13,206,973 / 9,549,818 / 9,375,608 / 174,210（原已核对27选区）；
- 平地：101,955 / 50,838 / 49,333 / 1,505；
- 山地：112,242 / 65,365 / 63,831 / 1,534。

平地、山地各自选举人数及投票人数来自次级统计表，三类之和与独立官方总量逐项相符，有效票各自与政大原表一致。仅使用次级表的统计行，不采用其存在错误的候选人行；尚未取得分票种原始官表。平地与已收录县市统计的差额为7/33/0/33，山地30/17/2/15；不将差额分摊。华加志2票地理归属仍待查。
