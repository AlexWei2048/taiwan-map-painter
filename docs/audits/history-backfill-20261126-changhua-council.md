# 1994 年彰化县议员：县级官方概况补录

资料来源：[101 年彰化县统计年报](https://ctrl.chcg.gov.tw/files/101%E5%B9%B4%E5%BD%B0%E5%8C%96%E7%B8%A3%E7%B5%B1%E8%A8%88%E5%B9%B4%E5%A0%B1_16_1081217_2025.pdf)，表 3-9，第十三届，印刷页 120–121。该表标注数据来自彰化县选举委员会，投票日期为民国 83 年 1 月 29 日。

| 项目 | 官方数值 |
|---|---:|
| 选举人数 | 808,327 |
| 投票数 | 646,504 |
| 有效票 | 632,982 |
| 无效票 | 13,522 |
| 候选人 | 109（男 91、女 18） |
| 当选人 | 54（男 43、女 11） |

8 个现有选区的候选人记录合计 109 人、有效票 632,982、当选 54 人，均与县级资料吻合；有效票加无效票也等于投票数。县级概况存入独立来源文件，由历史模块核对后与已有县级概况一起读取。没有把县级选举人数、投票数或无效票按比例分摊到 8 个选区，也没有由全县性别总数推定单个候选人的性别。原来关于选区投票统计和候选人属性的审计缺口保持待补。
