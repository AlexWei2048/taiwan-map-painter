# 1994年苗栗縣卓蘭鎮鄉鎮市長選舉補錄

- 出處：<https://gozhuolan.com.tw/wp-content/uploads/2023/09/13%E4%BA%BA%E7%89%A9%E7%AF%87.pdf>，《卓蘭鎮志·人物篇》張明豐傳，頁951。文字記載「民國83年的第12屆鎮長選舉」張明豐以 **4,635票** 擊敗詹豐治，順利當選，後於第13屆連任。
- 前任記載：同書《政事篇》列第10、11屆陸慶助；第12、13屆張明豐。參見 <https://gozhuolan.com.tw/wp-content/uploads/2023/09/05%E6%94%BF%E4%BA%8B%E7%AF%87.pdf>。
- 本批新增張明豐姓名、當選標記、實際得票4,635，並記載選舉時不是現任鎮長；對手詹豐治姓名有明確出處，但其得票、號次、推薦政黨和性別繼續留空，**不聲稱完整候選人名單**。
- 補錄儲存於 `sources/history-1994-township.json` 與 `assets/history-local-1994.json` 的獨立部分開票結果，不覆寫原苗栗縣級29人等統計摘要，不把個別當選票直接當成全選區有效票。
- 網頁顯示於「歷史數據 → 1994年鄉鎮市長 → 1994年鄉鎮市長補充檔案」。
- 原PDF公開文字可檢索，但本次頁面影像擷取失敗；若有當屆選委會開票公告，應再與原票數複核。
