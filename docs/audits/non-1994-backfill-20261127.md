# 非1994年历史资料交叉核验（2026-11-27）

- 1992山地少数民族民代：政大所藏中选会原表与斯坦福研究9位候选人的票数确认全区63,831票。地方明细63,829票，差额华加志2票，作为无地理归属的对账残差记录，不虚构乡镇或县市。选举人数、投票人数、无效票仍需可靠原表；维基候选人票表本身有误，不能单独用于补齐这些统计。
- 1992区域民代：更正审计旧清单误报，已覆盖359乡镇；仅金门、马祖的10乡镇票表及高雄市11区部分投票概况仍待核实。
- 1998屏东县：选委会第336次会议纪要第2页确认1998年山地议员8席；第3页所列妇保2席是2009年资料，不能证明1998年为2席。保留旧制推算1席及冲突状态，附官方出处。
- 1996/2000台南市中区、西区旧边界与2018台北市重计票分区表尚缺可靠原件。不将现代边界或投票日分区结果冒充原件。
- 1994不修改。
