# 曾当选或曾参选县市长政党徽旗追查

- 台湾建国党：官方编号202，财报页明确标注党旗；上轮运行日志显示已下载但未发布。https://party.moi.gov.tw/PartyFinancialChecklistContent.aspx?fs=1362&n=16101&s=261&sms=13073
- 保护台湾大联盟：官方登记未上传徽章 https://party.moi.gov.tw/PartyMainContent.aspx?n=16100&s=169&sms=13073 ；历史百科明确列出 TDA logo.jpg 党旗文件，但原页未获取，导入程序尝试精确文件。组织官网入党声明明确独立建国主张 https://www.taiwantda.org.tw/en/%E9%97%9C%E6%96%BC%E6%88%91%E5%80%91/%E7%94%B3%E8%AB%8B%E5%85%A5%E9%BB%A8 ，据此加引号。
- 台湾吾党：财报链接 https://party.moi.gov.tw/PartyFinancialChecklistContent.aspx?fs=810&n=16101&s=156&sms=13073 尚未取得原图。
