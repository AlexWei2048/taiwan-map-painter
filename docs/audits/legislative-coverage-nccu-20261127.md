# 立法机构民代历史数据完整性复核（2026-11-27）

## 为什么此前十届均显示“部分缺失”

完整性 UI 在 `history-coverage.js` 中直接检查每个 `assets/history-legislative-YYYY.json` 的 `registered_voters`、`ballots_cast` 和 `invalid_votes`，即使该届已在单独的 `assets/history-legislative-turnout-YYYY.json` 通过投票人数及候选票合计验证，仍当作缺项。此外，完整性颜色把 `gender` 和 `incumbent_at_election` 与逐候选人得票、当选标记放在同等必要级别，导致每届被错误标记。

本轮修复：完整性模块按选举年、票种、历史县市和区域选区核对两份已收录资料；仅当四项统计 `[选举人数,投票人数,有效票,无效票]` 均为非负整数、选举人数≥投票人数、投票人数＝有效票＋无效票、有效票＝该选区候选人票合计才承认投票统计。多选区县市不能拿整县统计替代其中某一选区。1992—2004旧制不分区依政党候选人票汇总计算席次，不要求另有独立政党票投票人数。性别与现任继续在缺失字段中披露，但不以此否定已核实的选举结果。

## 1992年剩余真实缺口

- 山地少数民族民代全国候选人票：**63,831票**，政大逐乡镇市区明细合计 **63,829票**，差额来自候选人华加志 **2票**，地方归属未知。保持两种来源的原始口径，不人为分摊2票。
- `assets/history-legislative-turnout-1992.json` 尚未存储该票种的经官方独立核验的 **选举人数 / 投票人数 / 无效票** 三项。第三方整理页面出现 `[112242,65365,63831,1534]`，算术自洽，但尚未追溯到政大或中选会1992年原始选举概况表，因此**未以“官方已核实”资料发布**。
- 1992年台北县候选人高文良的选举日现任身份仍待原始任职史核查；性别已从政大来源匹配，现任不能据姓名、胜负臆断。
- 以上缺口不足以否定其余候选人票、当选席次和县市统计的完整性，但1992年整届状态继续标记“部分缺失”。

## 来源及复现

1. **政大选举研究中心（优先）**：https://vote.nccu.edu.tw/cec/cechead.asp ，历届公职选举：https://vote.nccu.edu.tw/cec/ceclist.asp ；1992区域选区及原住民族民代逐候选人源数据已被本仓库的补档脚本引用与校正；历史详细来源记录见 `assets/history-legislative-candidates.js`、`assets/history-legislative-1992-local.json` 与 `reports/nccu-1992-legislative-turnout-audit.json`。
2. **中选会**：https://db.cec.gov.tw/ElecTable/Election?type=Legislator ；2001及其他年份四项投票统计的原始归档、核实依据见 `assets/history-legislative-turnout-YYYY.json` 的 `audit`。
3. **TaiwanVotes（辅助）**：https://www.taiwanvotes.tw/download/ ，该站公开立法机构民代年度资料始于1995年，不能用其缺少1992年记录推论当届不存在。
4. 既有资料不应以“候选人主档某字段为 null”直接推断该票种投票人数未知。原报告 `reports/data-completeness*.json` 使用原始主档扫描，包含与本次正式页面完整性不同的原始字段检查口径；查网页真实状态应采用本次跨文件核验，历史原始缺字段仍供修复使用。

本轮只修改判定与审计，不新增未经核实的候选人得票；九届“已收录”来自原有历史主档与经来源核对的投票数据重新合并验证。
