# 非1994年补档第三轮

2002年台南县杨振基（6号505票）及花莲县郭远华（8号511票）：现任字段以当届次级数据库与前届完整选举名单交叉验证补为非现任，证据等级为前届名册推定而非当届任职原件，原政大异常M保留于来源记录。至此旧审计所列2002年5名缺现任字段已补；待原始任职证据可复核更正。未改变候选人票数及当选记录。

1992年新的来源线索：黄纪教授TPGIS 2.0已从纸本选举实录手工重建1992年数据，见 https://ah.lib.nccu.edu.tw/bitstream/140.119/133375/1/411.pdf 及 https://ah.lib.nccu.edu.tw/bitstream/140.119/133376/1/412.pdf 。尚未获得可下载的原始投票表，不能声称补齐。1992年学术统计中选会来源有效票9,488,772减区域9,375,608及平地49,333恰为山地63,831，进一步支持全国有效票；投票数统计存在不一致，不据此推定山地其他字段。见 https://media.neliti.com/media/publications/540249-electoral-politics-in-taiwan-20082012-85425a88.pdf 。

1994原始数据不改动。
