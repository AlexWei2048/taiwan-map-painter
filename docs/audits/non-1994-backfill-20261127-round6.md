# 非1994补档续查

上一轮全国投票统计修正已通过基础测试、数据审计和线上验证。

1992高雄市：市政府《高雄市行政概况》表14（印刷页28）独立记载区域候选人27、应选12、选举人数889793、投票人数668677，恰与既有两区合计一致。补入官方来源及自动测试；未改变已核对票数，11个行政区的投票数及无效票依然缺少原件。
来源：https://orgws.kcg.gov.tw/001/KcgOrgUploadFiles/412/relfile/74512/221666/19de2986-24f6-4707-8e17-ad4ef04b2e72.pdf

1998屏东：找到选委会发布的第14届议员逐投票所得票档 https://web.cec.gov.tw/api/file/a32b8600-c34a-4652-9ff0-54c3867fa13e.pdf 。该表不含妇保公告，不能据实际女性当选数倒推妇保名额。中选会性别统计说明确认1999年及2010年规则变更，不能套用现代2席。保留旧法推算1席和来源冲突状态。原件书名《屏东县第十四届县议员选政志要》，中山大学论文参考文献确认存在：https://ethesys.lis.nsysu.edu.tw/ETD-db/ETD-search-c/view_etd?URN=etd-0902102-183649 。

1992马祖：马祖日报历史新闻查询 https://data.matsu-news.gov.tw/main.php ；纸本数字化月档 https://client.matsu.idv.tw/literature/matsunews/1992_12.pdf 。网页工具因文件过大无法读取，当前容器无法解析域名。新增一次性只读档案检查工作流，不写入数据。

1996/2000台南：中西区公所 https://web.tainan.gov.tw/tnwcdo/cp.aspx?n=19777 记载1982和2002里界变化；西门路部分路段曾为旧区界的次级线索不能替代完整历史矢量。原图仍待提取。

2018台北：台北地院107年度选字第7号判决附图2使用1563投票所重计票趋势，监察院新闻稿 https://www.cy.gov.tw/News_Content.aspx?n=125&s=14916 证明此图存在，但不包含逐票所数字原表。法院原发布 https://jirs.judicial.gov.tw/GNNWS/NNWSS002.asp?id=394197 公布全市结果；各区重计票明细仍待原表。

1994年不改动；未找到真实缺值不作填补。
