# 1994桃園縣13鄉鎮市長當選人：完成姓名補錄，候選票表仍缺

## 結果口徑
- 根據現有地方公所、公報、官方函釋、採訪和歷任首長表，本批新增7位先前未錄入者；原桃園市、中壢市、平鎮市、蘆竹鄉、龜山鄉、觀音鄉6位保留。**13個鄉鎮市均有一名當選者姓名，但沒有完整的逐候選人票數表，不能宣稱完成該縣開票結果**。
- 1994年第12屆桃園縣全縣共29位鄉鎮市長參選者，來源原已見 `sources/history-1994-township.json` 之縣級官方統計；本批不將13名當選者等同29名候選人。
- 地名沿用1994年行政名稱（例如八德鄉，1995年才改制為市）。
- 所有新增個人得票、號次、1994政黨推薦、性別均為 `null`；不以1998年得票或政黨反填1994年。
