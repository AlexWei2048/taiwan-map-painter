# 1992马祖原始报纸补档

原件：https://client.matsu.idv.tw/literature/matsunews/1992_12.pdf#page=39，1992年12月20日第二版（PDF第39页），SHA256 6c3c87298b2bc80e22660f9f0fde2e078cdc0d56087c22562109ee53b43398cb。县选委会公布的投开票情形明确记载山地选举3名选举人、2人投票、华加志获2票。此前山地全区63,831与地方63,829差2票现已闭合，连江县统计3/2/2/0。乡镇选举人数分票种未载，保持空缺；南竿山地2票由原报混合投票总数减区域有效及无效票得到。全区山地地方统计仍差27名选举人、15张无效票及15名投票人。

区域原报逐村票数汇总为曹原彰1192、曹尔忠1615，与正式全县1159/1648分别相差33票。唯一能使两人县级票数完全闭合的单组候选人票数互换为塘岐、后沃171/138→138/171。采用该**对账推定**供地图、CSV和表格展示，保留原始数字及待独立原始票表核验标记，不声称是官方更正。四乡区域得票与有效、无效票完全闭合；乡镇选举人数原报混合票种，未作分摊。详细逐组原始记录见 sources/history-1992-matsu-newspaper.json。

金门6乡镇、高雄11区投票统计、台南历史边界、屏东妇保及2018台北重计票分区仍待原始资料。1994不修改。
