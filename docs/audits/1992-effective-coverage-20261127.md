# 1992年有效资料统一核对

从已核验的投票概况分片关联27个区域选区、25个县市及全区统计。每个选区的有效票必须与候选人票数相同；分区总计须与县及全区一致。区域统计：13206973 / 9549818 / 9375608 / 174210（选举人数、投票人数、有效票、无效票）。

三个旧报告所列候选人附加字段缺口已由现有候选人补充档覆盖。新的缺项清单区分乡镇层级、选区层级和不适用的旧制政党票。
