## 补档标准

原始得票数来源必须可以逐选区、候选人核验。优先中选会与县市选委会当届原件，再参考政大、地方统计年报与 TaiwanVotes 交叉对照；数据相异保留来源与冲突原因。按县市或选区批次关闭缺口，未全额核实者仍标注“部分资料”。推送后运行数据完整性审计、历史数据及页面回归测试，并验证 GitHub Pages 部署。

**统计口径**：本次内容改进是 2001 年旧制民代投票统计正式回源及测试准确性；未对 1994 年候选人完整名单做无证据的补齐，也不宣称这批已经完成 1994 年缺档。

## 2026-11-27 续补：1994年南投县六个乡镇市当选人

从当届历任首长表及政府回顾资料、新闻交叉对照，补录此前南投县部分来源档中没有列出的第12届乡镇长（南投市为第5届）：南投市林俊梧、草屯镇赖忠政、埔里镇张鸿铭、竹山镇许文钦、鹿谷乡林民政、仁爱乡沈明德。分别保存逐人来源、前届任职者及按任期表推定的现任状态，任期表证据级别标记为次级，不能作为投票日逐人任职证明；其中林俊梧得到南投县政府回顾证实，许文钦有学位论文的1994年同期记述，沈明德有地方新闻列明第12届。

原档 `sources/history-1994-township.json` 与网站公开档 `assets/history-local-1994.json` 同步追加一条带6人的部分选举资料；未经核实的号次、性别、当届推荐政党、个人得票数均保持 `null`。既有集集镇林明溱不重复添加，所有此前候选人的票数和选区结果保持不变。新增 `tests/history-1994-nantou-partial.test.cjs` 检查双份来源一致、六个唯一地名、确实没有伪造票数以及89个完整选区计数不变。

**补档实绩：南投县6个乡镇市的历史当选人身份新增，完整选区仍89/319、待补完整票表仍约230个选区。** 当届原始票表见台湾地方文献资料库1995年《南投文献丛辑》（四十）第101–112页档案线索：https://twlld.nmth.gov.tw/literal-detail/234/17/1 ，其网页尚未提供可逐候选人提取的原表，未以推算结果补值。

## 2026-11-27 台中县龙井乡、清水镇官方乡志交叉补录

通过台中市政府公开的《龙井乡志》大事纪（https://www.taichung.gov.tw/media/267771/661416535671.pdf）核实：1994年1月29日刘瑞龙连任第12届龙井乡长，1994年3月1日就职；之前1990年已当选第11届。新增「龙井乡—刘瑞龙」1个当选人记录，现任属性标记为已由前届、当届任期证据确认；得票、号次、推荐政党和性别未查获，继续留空。

通过台中市政府公开《重溯清水镇志》（https://www.taichung.gov.tw/media/270401/551110255171.pdf）大事纪1994-03-01明确记载「吴金生连任第12届镇长」；对已经收录的清水镇吴金生补充现任属性及出处，没有重复添加当选人。

这两项为当选人层级局部补全，1994年319个乡镇市的**完整逐候选人选区**数量仍为89。发布档与原始补档资料同源同步，加入回归检查。
