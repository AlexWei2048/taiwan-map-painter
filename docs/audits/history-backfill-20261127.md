# 历史选举数据补全记录（2026-11-27）

## 已完成并推送

- 2001 年区域民代投票概况从前端临时修正转为正式数据资产：补齐全地区四项统计 `[15550197,10311453,10174005,137448]`、台北县及高雄市县市级四项、台北县第 2 与第 3 选区、高雄市第 1 选区，以及台北县新店市、汐止镇两处此前缺失的乡镇统计。此前仅存储为临时修正的三重市、旗津区统计也已同步回源。
- 已核对 25 县市及 369 个乡镇市区的四项汇总与全地区一致，旧候选人得票原档未动。
- 来源：`sources/history-legislative-2001-vote-reconciliation.json`（CECDataSet 中选会来源、政大第 3 选区资料、补计原始对账记录），对账测试：`tests/history-legislative-2001-profile.test.cjs`。
- 1995 / 1998 / 2001 / 2004 旧制多席次区域民代共 27 / 29 / 29 / 29 个选区：县市下只有一个选区时使用同票种当届县市的已核实四项统计（现有 `history-legislative-turnout.js` 的单选区回退），不能据 `ballots.regional.district` 的键数量将单选区误判为缺档。1992 年 27 个区域选区也满足此规则；新增 `tests/history-legislative-legacy-effective-coverage.test.cjs`。
- 以上是投票概况覆盖，并不代表逐候选人县市/乡镇得票、历史界线、现任身份等所有字段均完整。

## 继续需要原始资料的主要缺口

1. **1994 乡镇市长**：8 个县市部分/全部取得完整选区结果，合计 89 / 319 个选区；其余约 230 个仍未形成完整逐候选人得票，虽已有部分候选人数、当选人姓名、县市级选举统计。关键原始资料 `sources/history-1994-township.json`。
2. **1994 金门议员**：62 名参选、16 名当选；仍待 38 名完整候选人资料。先核当届结果清册，再逐候选人得票、号次、政党，不以当选名单代替完整记录。
3. **1994 议员字段**：尤其是现任身份、性别以及分选区选举人数、投票数、无效票。不得据未列入不完整的上届名册判断“非现任”，也不能用县级统计分摊填造选区票数。
4. **1992 其他层级**：金门与马祖乡镇民代结果、高雄市部分乡镇投票概况、山地少数民族民代全国与地方 2 票差异；县市级完整不代表乡镇级完整。
5. **1996/2000 台南中区与西区**历史轮廓，以及 **1998 屏东县山地议员共享妇女保障席位**待核公告。

## 补档标准

原始得票数来源必须可以逐选区、候选人核验。优先中选会与县市选委会当届原件，再参考政大、地方统计年报与 TaiwanVotes 交叉对照；数据相异保留来源与冲突原因。按县市或选区批次关闭缺口，未全额核实者仍标注“部分资料”。推送后运行数据完整性审计、历史数据及页面回归测试，并验证 GitHub Pages 部署。

**统计口径**：本次内容改进是 2001 年旧制民代投票统计正式回源及测试准确性；未对 1994 年候选人完整名单做无证据的补齐，也不宣称这批已经完成 1994 年缺档。
