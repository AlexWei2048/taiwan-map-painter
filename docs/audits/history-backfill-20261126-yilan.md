# 1994 宜蘭縣議員：利用中選會1990年完整當選清冊補錄前屆現任推定

- 中選會官方原件：<https://web.cec.gov.tw/api/file/0965a18d-e101-4921-bee3-e56b5e0dd062.pdf>，3頁，第十二屆1990-01-20選舉結果，逐區列33名當選者、性別、票數及推薦政黨。
- 1994第十三屆10個選區69名候選人，原先已驗證正向25人、負向5人、未知39人。本次使用33名當選者完整名單精確比對，37名原未知者未出現在1990年當選名單，新增來源佐證的推定 `incumbent_at_election=false`。
- **保留兩位未核對**：「陳秀暖」與前屆當選者「陳淑暖」相差一字；「林榮木」與「林榮星」相差一字。兩人維持 `null`，避免把可能的姓名誤植誤判為非現任。
- **分類意義限制**：官方1990年選舉結果代表前屆當選，不是整段1990–94年議員遞補或離職的人事錄；新補37條 `false` 屬當屆選舉前屆名單未匹配之推定，不能視為對1994-01-29在任狀態的逐人直接證明。
- 1990年PDF可讀文字已核對；原頁截圖功能回傳cache miss，故未使用影像進行第二輪比對，留待當屆官方紙本複核。
- 舊票數、當選、黨籍、候選人性別與席次原值全部保留。逐人檢查紀錄：`sources/history-1994-yilan-prior-council.json`。跨歷史資料快照及票數不變的回歸測試：`tests/history-1994-yilan-prior-council.test.cjs`。
