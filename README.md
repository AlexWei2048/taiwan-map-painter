# 岛屿调色盘 · 台湾地图填色与预测

纯静态、MIT 开源的地图工具。支持县市、乡镇市区、村里，以及区域、平地原住民、山地原住民议员和立委选区；可点击填色、按得票渐变、制作2026地方选举预测，导出SVG和高清PNG。

## 2026预测流程

1. 默认进入“2026选举预测”，先选择县市长、议员或乡镇市区长，再选择县市范围。
2. 点击地图，或从候选人目录点击“预测本区”。名册自动载入：首长单选，议员按应选席次复选；可先保存未完成的选择。
3. 可填写预测得票数或得票率，并按完整数据排序建议当选者。空白不当0，同票不自动决定；同额、不足额选举涉及得票门槛，仅支持手动预测。
4. 地图可显示当选者/各党席次构成、席次最多党、预测第一高票者政党，或第一高票者得票率深浅。分段配色宽度表示各党预测席次比例，不表示选区内党派地理分布。
5. 使用“保存并预测下一区”逐区完成，或下载带候选人ID的CSV模板批量填写后导入。预测与原有填色、投票数据独立保存，可撤销、重做并通过JSON方案转移。

2026依公告妇保席次。单区排序纳入妇保，跨原住民选区妇保须按同县市、同身份整组绝对票数核对，不把合计数逐区重复套用。相关选罢法第67、68、70条：<https://law.cec.gov.tw/LawContent.aspx?id=GL000292>。

## 乡镇市区预测

县市长或议员预测中，将“预测层级”切换为“乡镇市区明细”，选择县市、选区与乡镇，或直接点击地图填写。

- 县市长：标记各乡镇当地胜出者，或填写候选人当地票数/得票率；当地胜负与县市最终当选分别保存。
- 议员：录入当前选区各候选人的当地票数/得票率；地图可显示当地第一高票、政党合计，或指定候选人。乡镇高票不表示独立分配席次。
- 竹北市、新竹市东区与北区按既有选区边界显示“本选区部分”。原住民乡镇记录与区域选区记录独立。
- 在“批量填写与汇总”下载含稳定选区、乡镇及候选人ID的模板；仅完整乡镇票数可明确操作汇总，百分比不直接相加。汇总保留原有当选人选择，需自行核对。
- 方案JSON与自动保存包含乡镇记录，旧方案继续兼容。

2026-10-29号次复核：325名待补中逐人补齐199名，仍有126名待核。候选人目录可“只看号次待补”并下载待核原因清单。洪健興/洪建興、楊士龍/楊仕龍存在登记与抽签姓名差异，未据此直接赋号。全部来源及逐人证据保存在源码包 `sources/election-2026/ballot-number-audit-20261029.json`。

## 地图与边界

- 县市22、乡镇市区368、村里7731个历史快照图形。
- 2026区域议员161区；另有平地原住民23区、山地原住民37区。
- 第11届（2024）区域立委73区；平地、山地原住民各是全国一个选区，各3席。县市筛选仅改变全国选区的局部显示，同一身份始终使用同一个选区ID。不包含不分区立委地理图层。
- 按选民身份切换图层，避免身份选区与区域选区相互遮盖。
- 县市、乡镇、选区边界独立调整。乡镇叠加使用原始完整边线，仅去重，不裁掉与选区/县界重合的线；保留海岸。修复拆分乡镇时形成的伪碎片，不按短线长度粗暴删除真实边界。
- 引线端点位于区域主体内部。图例、指北针和比例尺使用独立留白。移位离岛加框；导出不附加离岛说明文字。
- 县市顺序依用户指定2026县市长维基页面；单一立委选区不标数字1。

原住民议员范围来自中选会115年8月20日公告及上传选区表；区域立委范围来自官方CSV。地图经过简化，是选区示意图，村里图层不是2026实时行政界。

## 候选人和来源

“2026选区与候选人”收录447个选区资料，统一显示候选人数，含60原住民议员选区。字段包括范围、应选席次、妇保席次、候选人号次、姓名、性别、政党、现任；提供筛选、搜索、地图定位、CSV下载和直接预测。

底表为用户上传的2026登记Excel及六份官方登记PDF，全部2064条登记记录逐人匹配；已确认不符资格者按审定/抽签公开资料剔除。核查和号次来源保存在`sources/election-2026/`，无法确认的号次为“待补”。苗栗另有一名乡镇市长不符资格者未能可靠确认姓名，资格核查详情明确保留此项，不猜测删除。显示单一人数不代表对未取得的官方资料作出确认。

原姓名、简体显示姓名分开保留，保护人名“乾”等字形。现任字段沿用用户来源表对同一职位的标记。县市长、议员与乡镇市区长2026名册不用于虚构2026立委候选人。

## 颜色、党徽和方案

配色、党徽、名称、顺序统一在“配色与图例设置”管理；手动上色使用简洁政党画笔，劳动党在默认列表中位于无党籍前。内置27个核对过的政党标志，支持自定义名称、颜色、党徽上传和图例编辑；PNG/SVG内嵌党徽。第三方图资、文字转换和标志的许可见`THIRD_PARTY_NOTICES.md`及`dist/assets/LICENSE-*.txt`。

所有使用者方案只存当前浏览器，程序和源码包不含测试预测。JSON方案保留所有图层填色、得票、预测、身份筛选、配色、党徽和图例，兼容旧版方案。

## 离线与再生成

`dist/`可部署到静态托管。`dist/offline.html`是无需联网的单文件，内置地图、名单、程序和党徽。

```sh
python -m pip install -r requirements-build.txt
python prepare_elections.py
python test_boundary_geometry.py
python build_candidate_directory.py
python apply_ballot_audit.py sources/election-2026/ballot-research-20261029/east.json sources/election-2026/ballot-research-20261029/west.json
python build_town_prediction_areas.py
node --test test-election-core.cjs test-project-schema.cjs test-prediction-core.cjs test-workspace.cjs test-town-prediction.cjs
python make-offline.py
python package-source.py
```

检查覆盖区域选区县市覆盖/重叠、15个拆分乡镇真实共边、60个原住民议员范围、全国原住民立委44个局部图形、完整乡镇叠加线和引线端点；计算检查涵盖预测席次、妇保、同票、缺值、导入校验及方案兼容。
