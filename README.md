# 岛屿调色盘 · 台湾地图填色与选举工作台

[打开网站](https://alexwei2048.github.io/taiwan-map-painter/) · 纯静态 · 无需登录 · MIT开源

支持县市、乡镇市区、村里、议员选区及第11届立法机构民代选区；可自由填色、填写2026地方选举预测、浏览2022结果，导出PNG、SVG和CSV。

## 使用方式

1. 在“未来预测”选择“2026九合一”或“自由填色”。预测支持县市长、议员、乡镇市区长，包括身份选区及山地少数民族区长。
2. 选择范围后点击地图或选区列表，手选预测当选人，或填写票数/得票率。两类数据分别保留，改变地图显示方式不会删除已有选择。
3. 县市长和议员可切到乡镇市区填写当地得票。当地领先与最终当选分别保存；议员第一高票不等于该区全部当选结果。
4. “方案”可备份/打开JSON、下载CSV模板和导入预测。导入先显示变更范围；默认保留空白单元格对应的已有数据，明确输入0则保存为0。需要清空旧值时选择整区替换。
5. “导出”可预览图片与尺寸。完整标注版附密集区域放大图；紧凑版保留地图、必要编号对照和完整标注补充，减少附图。PNG按画布上限调整清晰度，大图可用SVG完整导出，手机也保留SVG入口。

预测名单包含号次、姓名、性别、政党、党徽和现任标记。得票显示模式导出已录入候选人的票数、得票率及手选/领先标记；缺值为“—”，部分录入推导的得票率带星号。此表不自动把议员第一高票解释成当选。

所有用户方案只保存在当前浏览器。请定期下载JSON备份；跨设备继续时打开备份文件。浏览历史结果时，自动保存和JSON备份仍保存原来的用户方案。

## 地图与图例

- 县市22个、乡镇市区368个、村里7731个历史快照图形；村里边界不是2026实时行政界。
- 2026议员选区共221个：区域161个、平地少数民族23个、山地少数民族37个。三类可并列或单独查看。
- 第11届立法机构民代区域选区73个。自由填色另有不分区政党、平地少数民族、山地少数民族三个独立乡镇图层，不虚构2026候选人。
- 各图叠加县市边界，选区及村里图可叠加乡镇边界；边界颜色、粗细可调整。全台模式只描内部共边，单县市恢复完整边界及海岸线。
- 小区域优先显示区内名称；乡镇替代编号按县市、由北到南（同纬度由西到东）排序。编号保持同一字号，放不下时按地理顺序分到两侧列，用定位点和引线指向区域。选区始终使用实际号次，县市视图完整标注；全国总览放大时自动重新计算选区编号布局。数字对照表置于地图下方，屏幕及导出均不覆盖标注。
- 马祖、金门、乌坵、澎湖设移位框，比例尺和指北针置于留白。地图仅为示意。
- 县市长最终当选图例统一使用政党＋席次；乡镇领先数量采用区/乡镇单位。图例只显示当前实际使用的类别。
- 政党列表支持拖动、键盘调整顺序及自定义颜色和党徽。查询表、编辑表、地图与导出共用当前方案的党徽配色。

## 2022历史结果

“历史数据”包含县市长、县市议员及乡镇市区长，采用独立的2022选区名额资料：215个议员选区、910个应选席次。

选区结果按统一的编号与身份类别匹配。范围完全一致时才在当前地图着色；确有变化或乡镇内拆分无法可靠比对的选区保留未匹配，不套用当前边界。身份选区范围以对应乡镇集合核对。多席次选区显示当选席次最多的政党，并列另用灰色。单县市的县市长图显示各乡镇当地领先者。

主图、局部放大图和导出使用同一结果着色。选区表可搜索并下载标准UTF-8 CSV。当前历史快照没有性别字段，表格用“—”表示，不推测补值。

历史数据整理自中央选举委员会选举资料库，经 [taiwanvotes.tw](https://www.taiwanvotes.tw/download/) 整理。授权及官方公告见 `THIRD_PARTY_NOTICES.md`、审计资料和页面来源说明。4条妇保当选标记补正在独立2022元数据中留有记录，原始906条当选标记保留，补正后910条。

## 数据版本与来源

2026名册当前为447个选区、2051名候选人，资料核对至2026-10-30，71人号次仍待核。程序更新日期不等于资料重新核验日期。原文姓名和简体显示姓名分开保存，保留“乾”等人名用字。现任字段沿用来源表对同一职位的标记。

稳定候选人ID、既有号次、性别和预测主键不因本轮程序修复改变。本轮没有新增任何候选人的资格或抽签号次结论。资格核验的既有限制及姓名差异仍在页面说明和审计文件中保留。

当前数据SHA256见 `sources/data-snapshot.json`。公开构建输入、资料来源及恢复办法见 [sources/README.md](sources/README.md)。地图资源按需载入，图层失败可重试；导出前等待必要几何载入完整。

## 本地运行与测试

直接从本仓库根目录运行静态服务器，无需构建步骤：

```sh
python -m http.server 8000
```

然后打开 `http://localhost:8000/`。不要直接双击HTML，浏览器本地文件限制会阻止JSON地图载入。

计算与回归检查（Node.js 22）：

```sh
node --test test-ui-contract.cjs tests/*.test.cjs
```

浏览器流程检查：

```sh
npm install --no-save --no-package-lock playwright@1.56.1
npx playwright install chromium
```

在一个终端运行 `python -m http.server 8765`，另一个终端运行 `node --test tests/browser-smoke.mjs`。浏览器测试使用独立情境，覆盖保存得票后保留手选、历史身份匹配、跨模式搜索下载、下载文件内容、导出颜色、CSV导入预览及手机宽度导出，并逐县检查22县市议员/区域立法机构民代编号、密集乡镇标注、全国放大补号及图下数字对照表。`.github/workflows/checks.yml` 在push/PR时运行这些检查。

## 重建资料与打包源码

网站直接使用已提交的静态快照，普通使用及代码修改不需要执行资料重建。

恢复固定公共输入：

```sh
python scripts/prepare_build_inputs.py
python -m pip install -r requirements-build.txt
```

从已核验的完整地图资产重建按需加载分片：

```sh
python scripts/split_map.py
```

更新选举图形时可运行 `python prepare_elections.py`、`python test_boundary_geometry.py`、`python build_town_prediction_areas.py`。这些命令使用归档中的投影几何及选区输入，以已提交地图为基础；运行后应核对差异，不将旧输入误当成新的行政界。

从固定审计输入重建2026候选人快照：

```sh
python build_candidate_directory.py
python apply_ballot_audit.py sources/election-2026/ballot-research-20261029/east.json sources/election-2026/ballot-research-20261029/west.json
python apply_wikipedia_ballots.py
```

党徽可通过 `python build_party_logos.py` 重建。2022得票快照的联网重建脚本为 `scripts/build_history_2022.py`，只有全部来源取得成功才覆盖；法定选区名额和修正记录继续以版本化审计资产为准。

下载最新完整源码请用 GitHub 的 **Code → Download ZIP**。`archive/build-inputs-20261030.zip` 只是固定数据输入归档，不是当前网站源码。需要本地生成源码包时，先提交本地改动，再执行：

```sh
python scripts/package_source.py --output release-source.zip
```

该命令仅打包Git跟踪的文件，排除浏览器保存的用户方案和本机预览状态。
