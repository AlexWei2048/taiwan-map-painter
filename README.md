# 岛屿调色盘 · 台湾地图填色与选举工作台

[打开网站](https://alexwei2048.github.io/taiwan-map-painter/) · 纯静态 · 无需登录 · MIT开源

支持县市、乡镇市区、村里、议员选区及第11届立法机构民代选区；可自由填色、填写2026地方选举预测、浏览2022地方选举和1996—2024年台湾地区领导人选举结果，导出PNG、SVG和CSV。

## 使用方式

1. 在“未来预测”选择“2026九合一”或“自由填色”。预测支持县市长、议员、乡镇市区长，包括身份选区及山地少数民族区长。
2. 选择范围后点击地图或选区列表，手选预测当选人，或填写票数/得票率。两类数据分别保留，改变地图显示方式不会删除已有选择。
3. 县市长和议员可切到乡镇市区填写当地得票。当地领先与最终当选分别保存；议员第一高票不等于该区全部当选结果。
4. “方案”可备份/打开JSON、下载CSV模板和导入预测。导入先显示变更范围；默认保留空白单元格对应的已有数据，明确输入0则保存为0。需要清空旧值时选择整区替换。
5. “导出”可预览图片与尺寸。完整标注版附密集区域放大图；紧凑版保留地图、必要编号对照和完整标注补充，减少附图。PNG按画布上限调整清晰度，大图可用SVG完整导出，手机也保留SVG入口。

预测名单包含号次、姓名、性别、政党、党徽和现任标记。得票显示模式导出已录入候选人的票数、得票率及手选/领先标记；缺值为“—”，部分录入推导的得票率带星号。此表不自动把议员第一高票解释成当选。

所有用户方案只保存在当前浏览器。请定期下载JSON备份；跨设备继续时打开备份文件。浏览历史结果时，自动保存和JSON备份仍保存原来的用户方案。

## 地图与图例

- 县市22个、乡镇市区368个、村里7731个历史快照图形；村里边界不是2026实时行政界。
- 2026议员选区共221个：区域161个、平地少数民族23个、山地少数民族37个。三类可并列或单独查看。
- 第11届立法机构民代区域选区73个。自由填色另有不分区政党、平地少数民族、山地少数民族三个独立乡镇图层，不虚构2026候选人。
- 各图叠加县市边界，选区及村里图可叠加乡镇边界；边界颜色、粗细可调整。**默认边界视觉层级**统一为县市 `#3C5D53 / 1.4 px`（深灰绿）、议员/立法机构选区 `#738B82 / 0.8 px`（中性灰绿）、乡镇市区 `#B1C3B9 / 0.5 px`（浅鼠尾草绿）。县市层的主边界直接采用县市样式；乡镇层主边界与叠加的乡镇界采用细线，叠加县市界保持粗线。网页 SVG/PNG 导出保留同一套视觉层级。旧方案中未修改的原默认边界值自动升级，手动自定义的边界颜色和宽度保留，仍可在“行政区边界”里按层调整。全台模式只描内部共边，单县市恢复完整边界及海岸线。
- 小区域优先显示区内名称；乡镇替代编号按县市、由北到南（同纬度由西到东）排序。编号保持同一字号，放不下时按地理顺序分到两侧列，用定位点和引线指向区域。选区始终使用实际号次，县市视图完整标注；全部地区总览放大时自动重新计算选区编号布局。数字对照表置于地图下方，屏幕及导出均不覆盖标注。
- 马祖、金门、乌坵、澎湖设移位框，比例尺和指北针置于留白。地图仅为示意。
- 县市长最终当选图例统一使用政党＋席次；乡镇领先数量采用区/乡镇单位。图例只显示当前实际使用的类别。
- 政党列表支持拖动、键盘调整顺序及自定义颜色和党徽。查询表、编辑表、地图与导出共用当前方案的党徽配色。

## 1996—2024台湾地区领导人选举（历史第二阶段）

按**选举类别 → 选举年份 → 地图层级**查看1996、2000、2004、2008、2012、2016、2020、2024共8届选举，地图只提供**县市**和**乡镇市区**两级，**不提供村里级地图**。1996至2008年保留25个当届县市，2012年起为22个当届县市，行政区名称同时保留当届官方写法及规范名称。

地图以各地最高票候选人及其政党着色，提供**得票领先、得票率、得票数**三种显示；领导人选举图例同时展示**政党＋台湾地区领导人候选人 & 副领导人搭档**（例如“中国国民党｜李登辉 & 连战”），并按参选组合独立统计，避免把同届两个独立连署组合误合并为一个图例项。2022县市长选举的**全台地图仍只显示政党**，选择具体县市后图例增加该县市候选人姓名。上述图例与SVG/PNG导出共用显示内容。得票率和得票数是不同的选项，不能互相替代。选举的当选标记只依据全台正式结果，县市或乡镇市区的领先不等于全台当选。选举概况中的全台选举人数、投票人数、有效票和无效票来自核验的各届统计；县市或乡镇市区没有可信对应统计时显示缺值，不按得票数推算选举人数。

早期改制之前的**台中市/台中县、台南市/台南县、高雄市/高雄县**分别作为不同历史县市建立地图，不把旧县当作现县市。县市边界线按照当届乡镇归属重新生成，乡镇层继续显示乡镇界；选择单一旧县市时，绘图、边界与缩放均仅包含该县市，不叠加合并后的现代县市边界。边界的区域隶属与范围已由逐年行政区核验；**几何线条沿用本站较新的乡镇边界图资，因此不能视为当年官方测绘边界精确复刻**，后续细微海岸线或测绘变化不应据此断定。同名而不相同的旧乡镇有专门的映射，例如原高雄县三民乡映射至现在的那玛夏区，不会误画到高雄市三民区。1996、2000年的台南市中区、西区旧界线在现有乡镇数据中不可单独还原，因此**明确标注“中区、西区（合并）”并合并显示两区得票**；原始中区、西区得票记录仍保留在按乡镇市区导出的CSV中，避免将现代行政边界冒充旧界。

8届数据按年份拆分为独立JSON文件 `assets/history-president-YYYY.json`，切换年份时按需加载并缓存，加载失败时不会覆盖上一份可用数据。Python构建脚本 `scripts/build_history_presidential.py` 会核对每年历史县市数、候选名单、县市合计及全台官方有效票数；文件哈希与来源见 `sources/history-presidential-manifest.json`。自动构建流程为 `.github/workflows/history-presidential.yml`，本地核验：`python scripts/build_history_presidential.py --verify-existing`，网站回归与浏览器测试核对历史选区映射和切换交互。本轮还对八届全部历史县市进行乡镇来源、县市范围、边框包含关系及2008年县市分立的全六区浏览器检查。

历史数据来源与版权声明保持在网页原有的统一来源区域，**历史数据访问权限保持仅所有者可访问**；其他用户点击仍显示“开发中，敬请期待”。

## 2022历史结果

“历史数据”包含县市长、县市议员及乡镇市区长，采用独立的2022选区名额资料：215个议员选区、910个应选席次。

历史工作台按“选举类别—选举年份—选举类型—地图层级—地图范围—地图显示内容”逐级筛选，并提供“结果地图、候选人结果、选举概况”三个视图。县市议员可分别查看区域、平地少数民族和山地少数民族选举；选择“全部类型”时，三类投票率分别列示，不合并可能重叠的选民。得票率与得票数采用两个独立的地图显示选项：得票率用于比较不同地区的相对支持度，得票数用于查看实际票量，避免因各选区选举人数不同而混淆两种指标。

选区结果按稳定编号与身份类别匹配。范围完全一致时才在当前地图呈现；确有变化或乡镇内拆分无法可靠比对的选区保留未匹配，不套用当前边界。县市议员地图使用中性底图，通过党徽和席次数显示完整当选构成；拥挤选区使用编号、外置卡片和引线。县市长的乡镇市区地图只表示“得票领先”，不把地区领先写成当选。

候选人表可按姓名、地区、政党搜索，并按政党筛选；不同选区或乡镇市区使用分组标题区隔，“当选”列只显示官方当选标记图片，不根据票数自行推断。选举概况统一显示选举人数、投票人数、投票率、有效票、无效票、有效率、候选人数和当选人数；议员“全部类型”按区域、平地少数民族和山地少数民族分别统计。县市长结果可从县市层级下钻到乡镇市区得票分布，乡镇市区候选人表仍以全县市官方结果标记最终当选人。

主图、席次徽章、结果表和导出使用同一数据。SVG/PNG文件名包含年份、类别、范围和指标；历史CSV同时保留规范名称与官方原始名称。第一阶段仍处于开发期，公开访客点击“历史数据”只会看到“开发中，敬请期待”，获授权的测试环境可使用完整工作台。

历史数据整理自台湾地区选举事务主管机构公开资料，经 [taiwanvotes.tw](https://www.taiwanvotes.tw/download/) 整理，并参考政治大学历届公职人员选举资料。网页左下角统一列出数据来源，不在各结果面板和导出图片中重复显示。运行时快照采用版本2实体结构，包含选举、选举区、候选记录和来源校验信息。授权及官方公告见 `THIRD_PARTY_NOTICES.md`、`sources/history-2022-manifest.json`及审计资料。4条妇保当选标记补正在独立2022元数据中留有记录，原始906条当选标记保留，补正后910条。

```sh

npx playwright install chromium
```

### 地图行政区索引排版（2026-11-11）

历史记录：2026-11-11曾采用地图下方独立索引布局；2026-11-12已根据要求改为地图画布内预留侧栏，保留自适应高度、条目滚动及双向高亮。

SVG/PNG 导出图中的行政区索引与图例另置于地图右侧独立栏中（索引在上、图例在下），保留全部编号与名称，最多自适应为四列，不叠压地图或指北针与比例尺。

索引键盘焦点与地图高亮采用互不干扰的状态判定；焦点停留在编号项时，即使页面自动滚动触发鼠标离开事件，也不会错误取消对应行政区的高亮。

导出图片仅保留索引标题和编号对照，不额外附加索引条目数量或说明文字。


### 涉台公开用语复核（2026-11-12）

依据《新华社新闻信息报道中的禁用词和慎用词（2502）》第49—86条：地图、范围下拉框、历史图例以及SVG/PNG/CSV中的“金门县”“连江县”分别显示为**“金门”“马祖”**，内部选区编号、原始记录和选项 value 不变。继续规范“原住民”“总统”“立法院”等公共文案。SVG导出先解析 XML，只处理显示文本和说明属性，防止替换底层区域标识符。


### 行政区索引回到地图内部（2026-11-12）

依据最新需求，互动索引位于地图画布内预留的右侧空白区，而非画布下方。按SVG实际比例与图例位置动态定位，上方避开缩放按钮与指北针，底部避免压住图例和比例尺，项目较多时仅索引内部滚动；地图仍保留完整标号及双向联动，导出索引继续使用图片右侧栏。之前地图下方的索引方案已由此替代。

“全台”作为含金门、马祖的整体显示范围时统一呈现为“全部地区”，避免把福建外岛误表述为台湾本岛的一部分；地图选区与历史数据库键值保持原值。

公开可访问的旧版入口 map-v60.html 同步使用新版显示用语修正脚本和地图布局样式，不再停留在旧缓存版本。


### 行政区索引随地图缩放与拖动（2026-11-12）

行政区索引现在使用与 SVG 地图一致的世界坐标系：默认位置仍位于地图右侧预留空白内，避让缩放控件、图例、指北针与比例尺；使用放大、缩小、拖动地图时，索引将与地图**等比例缩放并同步位移**，不再固定在浏览器画布上的某个像素位置。“适合画布”可以恢复起始排版。索引的滚动、点击、键盘及区域双向高亮均保留。静态导出的索引与图例继续采用独立侧栏，避免遮挡地理内容。


### 行政区索引紧凑排版（2026-11-12）

根据地图实际标注字号计算索引字体（保留约 7.5–11 px 的基本可读范围），避免索引使用明显大于地名的 UI 字体；整体宽度约 85–135 px，最大高度约 132 px（窄屏）或 184 px（宽屏），采用更小的行距、轻量编号及低对比度的描边与背景。索引靠地图右侧留白区对齐，继续随地图缩放、拖动并避让图例和指北针；项目多时在索引内部滚动。


### 行政区索引清晰度与导出布局（2026-11-12）

互动行政区索引不再使用 CSS `transform:scale` 放大已栅格化的 HTML 文字。地图缩放时依照 SVG viewBox 的比例重新排版索引宽度、高度、字号、内边距，地图拖动时同步更新整数像素位置，减少小字渲染模糊。导出图中的索引条目增大了矢量字体，并将索引与历史图例整体左移到地理布局预留的右侧空白区；导出结果表格根据图片最终宽度分配列宽，底部表格右端与图片保留一致的 40px 外边距，不再出现额外的大块空白。SVG 与 PNG 共用此布局。
