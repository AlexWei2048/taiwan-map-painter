# 岛屿调色盘 · 台湾地图填色

现在支持五个独立保存的图层：村里（7,731 个图形）、县市、乡镇市区、2026 年区域议员选区（161 区）、第 11 届区域立委选区（2024 年，73 区）。乡镇和两种选区图层均可独立调整选区/乡镇边界和县市边界。

## 村里与党徽

“村里”在全台同一张地图上显示，可按县市及乡镇筛选。大范围视图按缩放程度显示不拥挤的名称，悬停可查看完整名称；筛选乡镇时显示全部村里名称。此图层采用 **taiwan-atlas 1.0.2 的村里快照**，共 7,731 个图形，并非 2026 年实时村里边界。投票数据模板用 11 位村里代码匹配，村里名称包含乡镇以减少同名歧义。

内置 27 个已核对来源的政党标志，包括默认列表中有党徽的政党；“无党籍”“其他政党”没有统一党徽。未收录标志的预设可通过“编辑图例”上传、替换或移除党徽；新增自定义政党也可直接上传。支持 PNG、JPG、WebP、SVG，最大 2 MB，转换为透明背景小图后与方案一起本地保存。左侧列表、SVG 和 PNG 图例使用同一图档，无需外部图片服务。各标志版权和来源见 `assets/LICENSE-party-logos.txt` 及 `sources/party-logos/manifest.json`。

两种选区边界重新进行平面分区合并：填色多边形不再逐环描边，单独输出去重后的选区边界网格，并叠加县市边界，避免村里拼接细线残留。生成时逐县市检查覆盖缺口、越界和重叠，记录于 `sources/boundary-audit.json`；地图仍为简化示意，不能替代官方测绘边界。选区名称引线默认关闭，可在地图设置中开启。导出图片已删除离岛移位说明文字，移位离岛的框线保留。

## 得票渐变和数据

1. 选择图层及县市范围，切换“得票渐变”。
2. 选择按候选人排名，或合计同党候选人后按政党排名。候选人模式用其所属政党颜色；政党模式用该政党颜色。
3. 选择以最高票者的得票率或得票数控制深浅。数值越高越深，数值越低越浅。得票率默认范围为 0—100%；票数默认按当前视图最高值设置上限，也可以编辑上下限。
4. 点击区域编辑数据，或下载当前图层 CSV 模板后导入。提供全部票数时优先根据有效票总数计算得票率，未填总数时使用已录入票数合计。

应用不会自动填入真实选举或预测结果。最高票者仅根据用户已录入的数据计算。缺少数据、指标不完整或所有票数为零时使用浅灰底色；并列最高使用另一种灰色，均在渐变图例中说明。最高票者不表示多席议员选举的全部当选人。

CSV 列：`选区代码,县市,选区,候选人,政党,得票数,得票率(%),有效票总数`。代码必须对应当前图层；同名区域需填写县市。导入前显示校验结果，有错误时不修改已有数据。确认导入只替换文件中涉及区域的完整记录。建议使用 UTF-8 CSV。

“编辑图例”可改标题、补充说明、字号、各类别名称/颜色、显示状态及排列顺序；PNG 和 SVG 同步更新。保存方案包含五个图层的填色、投票数据、渐变范围和图例设置；旧版两图层方案仍可打开。

## 选区范围与图资版本

- 议员图层为 **2026 年区域议员选区**，依据中选会 115 年 8 月 20 日公告：<https://www.cec.gov.tw/central/article/63625>。村里对应关系参考 `kiang/db.cec.gov.tw` 的 2026 年整理资料。竹北市、新竹市东区/北区的拆分村里另与公告核对。
- 立委图层依据中选会第 11 届选区范围 CSV：<https://data.gov.tw/dataset/170247>，按官方村里名单生成 73 个区域选区。
- 原住民议员、原住民立委与区域选区涉及重叠的选民身份；不分区立委按政党名单投票，均未混入此区域选区图层。
- 完整乡镇沿用现有乡镇图形；拆分乡镇使用 taiwan-atlas 的村里图形合并，再与乡镇边界相交。地图属于简化示意图，不用于地籍量测。
- 澎湖、金门、马祖、乌坵为移位示意，均加框；绿岛、兰屿、琉球沿用主岛投影中的实际相对位置。比例尺以主岛投影中心为参考。

## 使用

直接双击 `offline.html` 即可离线使用。此文件内置地图、样式、程序、OpenCC 和政党颜色预设，不需要外部网络、CDN 或在线地图服务。浏览器若禁止本地文件保存，可使用“保存方案”下载 JSON；方案可在在线版或离线版互相打开。

在线部署：将 `dist/` 上传到任何静态网页托管服务。使用中国大陆可访问的托管和域名可以替换当前网址；本项目没有将现有 Sites 托管自动迁移到其他地区的能力，也没有验证现有网址的大陆网络可达性。

本地 HTTP 预览：

```sh
python -m http.server 8080 --directory dist
```

打开 http://localhost:8080。

## 功能

- 全台乡镇市区单图、县市层级、区域筛选、搜索、点击填色、橡皮擦、撤销和重做。
- 简体中文界面与地名。每个显示区域均有名称，使用实际多边形包含测试优先放在区域内；所有区域名称保持统一字号，放不下时使用间隔排列的外部标签。全台名称较小，可放大查看。引线在悬停时加强显示。
- 可编辑行政区边界颜色和粗细（0–3 px），可保存和导出。
- “颜色与图例”中的“新增自定义政党”：输入名称、选择颜色或填写六位十六进制色码，加入图例后自动选择该画笔。支持修改、删除和撤销，上限 64 个类别。
- 48 个政党/类别颜色预设，初始显示 11 个常用类别。颜色取自用户指定的 [Wikipedia 模板](https://zh.wikipedia.org/wiki/Template:中華民國政黨色彩/doc)，核对日期 2026-10-28。颜色目录不代表当前政党登记状态。
- 自动保存在当前浏览器；五种图层的填色与投票数据分别保存。支持 JSON 方案导入/导出、SVG 和 2400 px 宽 PNG 导出。

## 源码与数据

网页的“下载完整源码”提供可运行源码包，不包含 Git 元数据、托管凭据或用户方案。原应用程序采用 MIT 许可证，第三方许可证见 `THIRD_PARTY_NOTICES.md`。

几何数据由内政部行政区界图资经 [taiwan-atlas](https://github.com/dkaoster/taiwan-atlas) 提供，输入为 `towns-mercator-10t.json`，采用该项目的 MIT 许可。边界经过制图简化，并非实时行政区服务。

`prepare_map.py` 生成独立 SVG 路径与标签候选点。地名与文本通过本地 OpenCC 转换为简体，重新生成图资需要 `opencc-python-reimplemented`。

更新文件后运行：

```sh
node --check dist/app.js
python build_party_logos.py
python make-offline.py
python package-source.py
```

## 制图版式更新（2026-10-29）

县市标签采用 11 个 SVG 单位统一字号；台北市、基隆市、新竹市、嘉义市使用引线，其余优先置于区域内，离岛县名置于对应框内。图例在地图右下角竖排，不含“未填色”；导出保留标题、地图、图例、指北针和比例尺，不再附加离岛说明文字。马祖、金门、乌坵、澎湖加框；其余岛屿保持实际位置。

比例尺依据 taiwan-atlas 1.0.2 的 mercatorTw 默认 scale=10000，以主岛投影中心（120.97°E，23.60°N）为参考，用 6371.0088 km 地球平均半径计算。来源投影代码与生成脚本见 https://github.com/dkaoster/taiwan-atlas 。离岛为移位示意，各框之间的距离不能使用主图比例尺量测。
