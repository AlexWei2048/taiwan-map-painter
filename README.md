# 岛屿调色盘 · 台湾地图填色与选举工作台

[打开网站](https://alexwei2048.github.io/taiwan-map-painter/) · 纯静态 · 无需登录 · MIT开源

支持县市、乡镇市区、议员选区及立法机构区域民代选区；可自由填色、填写2026地方选举预测、浏览1993—2022年地方选举、1996—2024年台湾地区领导人选举及1992—2024年立法机构民代选举结果，导出PNG、SVG和CSV。

## 1992—2024立法机构民代选举

### 2008—2024 不分区政党票：精确乡镇市区地图

- 选“历史数据 → 立法机构民代 → 年份（2008／2012／2016／2020／2024）→ 不分区民代 → 地图层级：乡镇市区（全台368个）”，可直接查看**368个乡镇市区**地图，而不必预先选县市。点击乡镇可直接查看该乡镇所有政党得票，画面自动缩放到所属县市；“返回全台”仍保留乡镇市区层级。
- 地图支持**各地领先政党**、**指定政党得票率**、**指定政党得票数**。指定政党按全区统一识别，切换县市不会把同党拆分成不同的候选人。得票率以**该乡镇市区全部有效不分区政党票**为分母；不以县市平均票数、人口或选民数推估。
- 五届的原始政党票分乡镇地区均为**368组**；2008年为当时**25个县市**，2012至2024年为当时**22个县市**。分别核对各政党从乡镇市区到县市、再到全区的原始票数，全部完全一致。各届有效票：2008年9,780,573；2012年13,162,072；2016年12,190,139；2020年14,160,138；2024年13,776,736。
- 2008及2012年的旧县市与乡镇市区名称按当届原始资料保留，现有368幅行政区底图一一映射为当届区域（不交叉分配票数）；**历史投票统计精确**，但改制或改名地区的地理轮廓仍使用可对应的现行行政区形状，并不承诺每一处旧行政边界的测绘级复原。
- 每次载入2008—2024年数据均自动验证政党票全国／县市／乡镇的逐党逐票一致性、368区唯一匹配、图形未复用与没有缺图；不通过校验就显示载入错误，**不会静默将县市票数分摊至乡镇**。底层数据来自[中选会选举开放数据](https://data.gov.tw/dataset/13119)，经 [Taiwan Votes](https://www.taiwanvotes.tw/download/) 原始最细地区票数整理，对应年份结果存在 \`assets/history-legislative-YYYY.json\`。

### 不分区民代：历届席次与名单

* **1992—2004（旧制）**：1992、1995年分别计算30个不分区与6个侨选席次；1998、2001、2004年分别计算41个不分区与8个侨选席次。各党推荐的区域及少数民族民代候选人票归集后计算5%门槛，合格政党按比例及最大余额法在两类名额中分别分配，女性最低名额依旧制规定。
* **2008—2024（新制）**：34个不分区名额直接按独立政党票分配，达到5%的政党按合格票重新计算得票比率，按最大余额法分配，各党当选名单女性不得少于一半。分配时小数点采用法定四位规则。
* **原始当选名单**：1992、1995、1998年分别收录当届**全部30＋6、30＋6、41＋8**名不分区／侨选原始当选人；2001、2004年分别收录全部**41＋8**名；2008、2012、2016、2020、2024年各收录**34名**原始当选人。2012、2016、2024年存在因妇女保障而由较后排名女性候选人当选的情况，名单使用实际当选人资料核对，而非只取前N名。任期内辞职、递补与补缺不计入选举当晚的原始当选标记。
* **政党提名资料**：2001年已录入5党108位不分区及21位侨选提名人（共129位），并按中选会会议确认的原登记顺序展示；2004年收录5党89位不分区及20位侨选原始登记候选人，已依据[第六届不分区及侨选公报](https://web.cec.gov.tw/api/file/7948d4c0-bd7a-4159-b4c9-5a3014c5d1e1.pdf)恢复国民党、民进党、亲民党正式排序，并按[中选会第341次会议纪录](https://web.cec.gov.tw/api/file/e1f90a1d-a838-4b32-82e7-eac0d7a5331a.pdf)更正台联撤销陈永兴登记后的1—9位有效排序。个别无党团结联盟及其他未完全确认的侨选名次保留无排名；2008、2012、2016、2020、2024年的不分区提名资料分别涵盖**12、11、18、19、16个政党**，原登记名册共**128、127、179、216、177人**，按当届公告顺序展示，并纳入未取得席次的小党。
* **资料完整度与边界**：1995年已依据[第三届不分区选举公报](https://web.cec.gov.tw/api/file/1e2b67f6-1a6c-4d9e-8a1e-778c1fe1b88c.pdf)补齐国民党28人、民进党19人、新党8人共55位不分区正式提名人及名次。1992、1995、1998年现均收录当届官方公报的不分区与侨选正式名单，分别为46＋9人、55＋11人、87＋14人，按正式公告顺序显示。1998年资格审定后的名单另与[中选会第249次会议记录](https://web.cec.gov.tw/api/file/8a0e1d95-b383-481b-adca-1393ba60643d.pdf)核对。资料不足时绝不将“当选名单”冒充“完整提名名单”，也不为旧制侨选获选者编造名次。旧制“有推荐候选人政党”不表示该党一定另行提出不分区名单；部分地区候选人政党与不分区参选政党并不等同。
* **数据核对与来源**：独立政党票与席次分配核对中选会历届选举数据；原始名单优先参照中选会历届登记公告及当选公告，2012年参照当届政府公报，1992—1998年当选名单交叉核实历史选举资料。可追查[2024年中选会完整提名公告](https://2024.cec.gov.tw/data/file/2fb887c81a7a4b3a888e4d3befe9259d.pdf)、[2016年中选会提名公告](https://web.cec.gov.tw/api/file/26f914ad-93b3-4c8e-9844-546ea286c970.pdf)、[历届选举资料库](https://db.cec.gov.tw/ElecTable)。早期资料缺失会在页面标示，不依计算配额虚构人名或当选顺序。


历史工作台收录1992、1995、1998、2001、2004、2008、2012、2016、2020及2024十届定期选举。区域民代的“地图层级”只保留**县市／选举区**；“全部地区（含金门、马祖）”属于“地图范围”首项，可以显示全台县市地图：全部地区的县市总览仅标县市名称；切换到选举区层级时仍显示全部地区的各个区域选区；**2004年及以前的多席选区在“县市”层级显示各县市的席次领先政党；切换为“选举区”层级时（包括全部地区），在每个区域选区上逐席显示当选党徽**。点入县市后可放大查看选区党徽，亦可聚焦单一选区查看候选人、当选人和党派席次。2008年起的单席选区按官方当选政党填色。**平地少数民族、山地少数民族和不分区政党票**在有地域数据的年份按全部地区／县市／乡镇市区展示，地图与表格分别呈现当地领先候选人、政党票数、得票率及原选举法定当选标记。该选项已统一改名为“**不分区民代**”：1992—2004年按各党推荐区域及少数民族候选人得票汇总计算，不存在单独的政党票；2008年起使用独立政党票。页面按年份自动切换制度，显示参选政党、5%门槛、得票数与得票率、法定席次分配、席次比例图和各党展开式原始当选名单，并提供详细计算规则。

不分区政党票、平地少数民族及山地少数民族候选人票在来源具备明细时可按全部地区（含金门、马祖）、县市及乡镇市区查看。1992年平地与山地少数民族候选人票已补录政大逐区明细，分别覆盖23个县市、359个乡镇市区；山地票的全区与地方明细相差2票，按各自档案显示。1992年区域民代保留当届候选人选区结果，不分区民代旧制计算票可汇总至县市。1995年以后数据由中选会开放资料的Taiwan Votes核对CSV构建；每个年度单独生成快照，来源文件、行数和SHA-256记录在 `sources/history-legislative-manifest.json`。

**历史地图边界核验**：1992—2004年区域多席选区按当届县市归属匹配现有乡镇市区边界。不得以合并后的现代县市名称作为唯一查找键；旧高雄市“三民区”与旧高雄县“三民乡”（今那玛夏区）是不同地区。2026年11月已修复该同名碰撞导致的2004年高雄市第一选区异常伸入山区的问题，并新增原始地理与浏览器测试。

**选举概况的数据口径**：历史区域民代、平地与山地少数民族民代及2008年起的不分区政党票，按票种读取已核验的历届投票统计（选举人数、投票人数、有效票、无效票、投票率、有效率）。1992、1998、2001年的部分资料只确认整届合计，此时在独立卡片显示“整届合计”，不将其当作某一票种的投票统计；2008年以前的“不分区席次计算票”不具有独立投票率。县市／乡镇市区层级没有对应可靠资料时保留缺值，不依候选人得票数推算登记选民或废票。内部选举识别码（如 `legislative:2004:regional`）只用于关联，不再作为页面文字。统计配置及出处见 `history-legislative-turnout.js`。

地方选举概况资料的拓展：已加入从中选会 `votedata.zip` 整理而来的 [MISNUK/CECDataSet](https://github.com/MISNUK/CECDataSet) 各地投票概况表，覆盖1995、1998、2001、2004、2008、2012、2016年的区域、平地少数民族和山地少数民族选举。自动构建脚本 `scripts/build_history_legislative_turnout.py` 将每个选区、县市和乡镇市区的**有效票**与本站单独整理的候选人有效票逐一核对：只保留票数完全一致的选举人数、投票人数、有效票、无效票和相应比例，防止跨年度、跨选区或新旧行政区名称错配。已发布的资料放在 `assets/history-legislative-turnout-YYYY.json`，来源文件与校验结果在分片的 `audit` 字段中。1992年没有该来源的地方数据，不能自行补齐。

已对十届立法机构民代选举的 3,632 条候选人记录进行字符异常初筛，并以中选会公告、机构资料和历届结果核实 11 条应修正记录。纠错来源与约束集中记录于 `sources/history-legislative-name-corrections.json`；保留人名中的「乾」「幹」，不因姓名较长就改写原住民或复姓候选人。可运行 `python scripts/audit_legislative_names.py` 重新生成审计清单。

运行 `python scripts/build_history_legislative.py` 可重新下载、验证并生成十个年度分片；运行 `python scripts/build_history_legislative.py --verify-existing` 只核验仓库现有分片。

## 使用方式

1. 在“未来预测”选择“2026九合一”或“自由填色”。预测支持县市长、议员、乡镇市区长，包括身份选区及山地少数民族区长。
2. 选择范围后点击地图或选区列表：议员采用仅预测胜负的方式，县市长和乡镇市区长可以录入票数或得票率。改变地图显示方式不会删除已有选择。
3. 县市长和议员可切到乡镇市区填写当地得票。当地领先与最终当选分别保存；议员第一高票不等于该区全部当选结果。
4. “方案”可备份/打开JSON、下载CSV模板和导入预测。导入先显示变更范围；默认保留空白单元格对应的已有数据，明确输入0则保存为0。需要清空旧值时选择整区替换。
5. “导出”可预览图片与尺寸，导出统一采用紧凑版，不再提供版式切换。保留地图、行政区索引、图例及必要的表格信息。PNG按画布上限调整清晰度，大图可用SVG完整导出，手机也保留SVG入口。

预测名单包含号次、姓名、性别、政党、党徽和现任标记。得票显示模式导出已录入候选人的票数、得票率及手选/领先标记；缺值为“—”，部分录入推导的得票率带星号。此表不自动把议员第一高票解释成当选。

所有用户方案只保存在当前浏览器。请定期下载JSON备份；跨设备继续时打开备份文件。浏览历史结果时，自动保存和JSON备份仍保存原来的用户方案。

## 查询链接与浏览器导航

切换历史选举类别、年份、地图范围、票种、地图指标、候选人、概况或趋势视图时，地址栏自动同步；复制网址即可分享并恢复查询条件。例：`#/history/council/2022/基隆市?level=district&metric=party`、`#/history/mayor/2009-2010`、`#/prediction/2026/mayor/台北市`、`#/free/town/台北市`。历史选区详情、概况范围和趋势比较年份也可随链接恢复。刷新及浏览器前进/后退支持相同路由；错误或已不可用的筛选项回到可用选项。Hash 路由兼容 GitHub Pages。URL 只保存视图与查询条件，不保存预测票数、当选预测、手动填色及自定义配色；这些仍保存在本机方案中。

## 地图与图例

- 页面提供县市22个、乡镇市区368个行政单位的地图；村里历史快照图形仍作为底层地理资料保留，但村里地图层级目前不提供。
- 2026议员选区共221个：区域161个、平地少数民族23个、山地少数民族37个。三类可并列或单独查看。
- 第11届立法机构区域民代选区73个。自由填色只保留区域民代图层；不分区、平地少数民族和山地少数民族历史选举结果在历史数据模块按票种浏览，不虚构2026候选人。
- 各图叠加县市边界，选区图可按需求叠加乡镇边界；边界颜色、粗细可调整。**默认边界视觉层级**统一为县市 `#3C5D53 / 1.4 px`（深灰绿）、议员/立法机构选区 `#738B82 / 0.8 px`（中性灰绿）、乡镇市区 `#B1C3B9 / 0.5 px`（浅鼠尾草绿）。县市层的主边界直接采用县市样式；乡镇层主边界与叠加的乡镇界采用细线，叠加县市界保持粗线。网页 SVG/PNG 导出保留同一套视觉层级。旧方案中未修改的原默认边界值自动升级，手动自定义的边界颜色和宽度保留，仍可在“行政区边界”里按层调整。全台模式只描内部共边，单县市恢复完整边界及海岸线。
- 小区域优先显示区内名称；乡镇替代编号按县市、由北到南（同纬度由西到东）排序。编号保持同一字号，放不下时按地理顺序分到两侧列，用定位点和引线指向区域。选区始终使用实际号次，县市视图完整标注；全部地区总览放大时自动重新计算选区编号布局。行政区索引表位于图例上方，与地图交互；屏幕及导出均不覆盖标注。
- 马祖、金门、乌坵、澎湖设移位框，比例尺和指北针置于留白。地图仅为示意。
- 县市长最终当选图例统一使用政党＋席次；乡镇领先数量采用区/乡镇单位。图例只显示当前实际使用的类别。
- 政党列表支持拖动、键盘调整顺序及自定义颜色和党徽。查询表、编辑表、地图与导出共用当前方案的党徽配色。图例自动显示，无独立图例编辑弹窗；历史结果从“历史数据”进入。

## 1996—2024台湾地区领导人选举（历史第二阶段）
SVG/PNG 导出图只保留图片顶部的动态年份及类别图名，取消底部候选人表格中原本误写为“2022 实际选举结果”的重复副标题，并同步缩小多余留白；此统一处理适用于历史结果与未来预测。经历届选举数据核验，1996—2024年台湾地区领导人选举的完整正、副职组合、各自性别和正职候选人在当届选举时是否在任已补齐，互动表格、导出表格以及县市/乡镇市区CSV同步更新。原得票数、政党、候选人号次及当选判定保持不变。


按**选举类别 → 选举年份 → 地图层级**查看1996、2000、2004、2008、2012、2016、2020、2024共8届选举，地图只提供**县市**和**乡镇市区**两级，**不提供村里级地图**。1996至2008年保留25个当届县市，2012年起为22个当届县市，行政区名称同时保留当届官方写法及规范名称。

地图以各地最高票候选人及其政党着色，提供**得票领先、得票率、得票数**三种显示；领导人选举图例同时展示**政党＋台湾地区领导人候选人 & 副领导人搭档**（例如“中国国民党｜李登辉 & 连战”），并按参选组合独立统计，避免把同届两个独立连署组合误合并为一个图例项。2022县市长选举的**全台地图仍只显示政党**，选择具体县市后图例增加该县市候选人姓名。上述图例与SVG/PNG导出共用显示内容。得票率和得票数是不同的选项，不能互相替代。选举的当选标记只依据全台正式结果，县市或乡镇市区的领先不等于全台当选。选举概况中的全台选举人数、投票人数、有效票和无效票来自核验的各届统计；县市或乡镇市区没有可信对应统计时显示缺值，不按得票数推算选举人数。

早期改制之前的**台中市/台中县、台南市/台南县、高雄市/高雄县**分别作为不同历史县市建立地图，不把旧县当作现县市。县市边界线按照当届乡镇归属重新生成，乡镇层继续显示乡镇界；选择单一旧县市时，绘图、边界与缩放均仅包含该县市，不叠加合并后的现代县市边界。边界的区域隶属与范围已由逐年行政区核验；**几何线条沿用本站较新的乡镇边界图资，因此不能视为当年官方测绘边界精确复刻**，后续细微海岸线或测绘变化不应据此断定。同名而不相同的旧乡镇有专门的映射，例如原高雄县三民乡映射至现在的那玛夏区，不会误画到高雄市三民区。1996、2000年的台南市中区、西区旧界线在现有乡镇数据中不可单独还原，因此**明确标注“中区、西区（合并）”并合并显示两区得票**；原始中区、西区得票记录仍保留在按乡镇市区导出的CSV中，避免将现代行政边界冒充旧界。

8届数据按年份拆分为独立JSON文件 `assets/history-president-YYYY.json`，切换年份时按需加载并缓存，加载失败时不会覆盖上一份可用数据。Python构建脚本 `scripts/build_history_presidential.py` 会核对每年历史县市数、候选名单、县市合计及全台官方有效票数；文件哈希与来源见 `sources/history-presidential-manifest.json`。自动构建流程为 `.github/workflows/history-presidential.yml`，本地核验：`python scripts/build_history_presidential.py --verify-existing`，网站回归与浏览器测试核对历史选区映射和切换交互。本轮还对八届全部历史县市进行乡镇来源、县市范围、边框包含关系及2008年县市分立的全六区浏览器检查。

一级入口为“岛屿画布”（未来预测、自由填色）和“岛屿图鉴”（历届选举数据），均向所有访客开放。首页预加载基础地图，脚本按依赖顺序延迟执行；首次进入岛屿图鉴时并行预取历史模块、按依赖顺序执行，选举结果按年份加载。跨届趋势以四路并发队列载入并复用进行中的请求，成功部署时间缓存5分钟并在页面空闲时查询。数据来源与版权声明见网页统一来源区域。

## 历届地方选举结果

“历史数据”的县市长按1993/1994、1997/1998、2001/2002、2005/2006、2009/2010合并同一批次的结果；县市议员的前三批均在同一年投票，显示1994、1998、2002，后两批显示2005/2006、2009/2010。各选区均保留原始投票日期。CSV 的年份列仍按各地实际投票年记录。乡镇市区长按实际投票年查询。具体县市、选区、乡镇市区的历史结果弹窗标题及候选人分组使用原始投票年份；现任列仅确认现任显示“是”，非现任及未核实资料留空（缺项有提示）。

得票数、政党和当选记录以[中选会原始档](https://data.gov.tw/dataset/13119)为基准，与[政治大学选举研究中心](https://vote.nccu.edu.tw/cec/cechead.asp)和 [Taiwan Votes](https://www.taiwanvotes.tw/download/) 交叉核对。三方不一致的原值和取舍记录在 [历史地方选举核对记录](sources/history-local-audit.json)。1993年县市长采用政大刊载的中选会资料，候选人表逐县市对账到选举概况。2018年台北市长采用法院重计后的全市票数；分区投票统计采用重计后数据，历史趋势的区级候选人得票采用[政大刊载的当日区级政党汇总](https://vote.nccu.edu.tw/cec/D2018635.PDF)与[中选会原始逐候选人区级表](https://web.cec.gov.tw/upload/file/2018-12-03/37318f85-8abe-4eb3-aade-98eb7f7879a8/7f52f9371d90a38a0280bee4e7a3cd3f.pdf)核对后的投票日口径。区级合计为1,414,816票，市级重计后为1,413,870票，两种口径在趋势说明中区分。2005年云林县议员第三选区采用中选会乡镇明细加总，该加总可与政大及 Taiwan Votes 对账。

1994年1月的县市议员补录覆盖22个县市、183个选区、1,807位候选人和867席，另有同批次12月的台北市、高雄市结果。1月资料来自[地方选务资料汇编](https://zh.wikipedia.org/w/index.php?title=1994年中華民國縣市議員選舉選舉區投票結果列表&oldid=95693813)，逐区核对候选人票数与有效票、当选人数与应选席次。台北县及高雄县使用地方选委会原件校正，来源在选区明细内可查。金门县的完整候选人明细缺档，已另行补录[金门县志](https://cabkc.kinmen.gov.tw/uploads/files/202304/ddcac480-e969-4887-89bb-91898049b65e.pdf)确认的5个选区16位当选人，以及官方统计年报的62名参选人、27,458名选举人、22,227名投票人（80.95%）；在地图说明中展开查询，来源和缺项见 `sources/history-1994-kinmen-partial.json`。地图与统计合计仅计入已收录完整结果，不把部分名单冒充完整得票资料。资料中的缺项按原样留空。补录文件由 `scripts/import_1994_council.py` 和 `sources/history-1994-council-corrections.json` 生成。

1994年乡镇市长候选人结果共覆盖88个选区，包括原台北县、原高雄县、新竹县、连江县、宜兰县，以及台东县海端乡、兰屿乡和云林县褒忠乡。宜兰县12个选区的25位候选人来自县选委会结果清册。罗东镇用《罗东镇志》补入选举人数及投票数，再扣除县选委会清册所列的有效票核算无效票。兰屿乡采用《兰屿双周刊》第145期刊登的四个投票所统计表。海端乡和褒忠乡的官方年报各列一名候选人，候选人得票等于有效票总数。褒忠乡年报所列选举人数与投票率无法对账，两项暂缺。新竹县新增资料来自《续修新竹县志》表3-3-24，连江县来自《连江县志》政事志及各乡公所档案。选区得票按候选人票数汇总，原档未列的政党、号次或投票统计保留缺值。[金门县志](https://cabkc.kinmen.gov.tw/uploads/files/202304/c035945e-0950-4aa7-aacc-1e2e1d815dc9.pdf#page=64)记载的六位金门乡镇长当选人另附在地图说明，可查当选得票及当时党籍。同一补充档案还收录[续修花莲县志](https://document.hccc.gov.tw/records/files/03/4-%E7%B8%A3%E8%AA%8C%E6%94%BF%E4%BA%8B%E7%AF%87.pdf#page=66)所载13个乡镇市的选举人数、投票数、有效票、无效票及投票率。台东县东河、鹿野、大武及云林县口湖的补充档案列出投票统计和当选人。口湖乡另据《口湖乡志》补齐四位候选人的姓名，个人得票待核。台东县池上乡补录第12届当选人。原桃园县、原台中县、苗栗县和彰化县另列县级投票统计。补充档案也收录云林县莿桐、四湖、斗南、西螺的投票统计及当选人、原台中县清水镇及大里市当选人、金门县乡镇长全县选举人数、投票人数、投票率及参选人数，以及政大《选举研究》刊载的澎湖县乡市长选举全县政党得票率。

历史议员及立法机构区域民代的结果弹窗列出当届乡镇市区范围，同一乡镇跨选区时标记“部分里”；已有核验里别名单（如新竹市）直接列示，未取得当届里名则不借用现代边界。2024年部分里选区可打开中选会原始公告。1992年只提供明确注明年份的参考归属。1999年以后缺失的区域议员妇保席次依当届适用规定（每满四席一席）计算并标注来源，既有官方数值不覆盖，早期或少数民族未确认的额度保留缺失。历史地图按当届行政区归属、以可对应的现行轮廓绘制。缺少可靠边界的议员选区仍可在候选人结果或选举概况中查询，缺少可核实的投票统计时显示空缺。2022年保留独立核验的215个议员选区和910个应选席次。

历史工作台按“选举类别—选举年份—民代类别—地图层级—地图范围—地图显示内容”逐级筛选，并提供“结果地图、候选人结果、选举概况”三个视图。县市议员可分别查看区域、平地少数民族和山地少数民族选举；选择“全部类型”时，三类投票率分别列示，不合并可能重叠的选民。得票率与得票数采用两个独立的地图显示选项：得票率用于比较不同地区的相对支持度，得票数用于查看实际票量，避免因各选区选举人数不同而混淆两种指标。

选区结果按稳定编号与身份类别匹配。范围完全一致时才在当前地图呈现；确有变化或乡镇内拆分无法可靠比对的选区保留未匹配，不套用当前边界。县市议员地图使用中性底图，通过党徽和席次数显示完整当选构成；拥挤选区使用编号、外置卡片和引线。县市长的乡镇市区地图只表示“得票领先”，不把地区领先写成当选。

候选人表可按姓名、地区、政党搜索，并按政党筛选；不同选区或乡镇市区使用分组标题区隔，“当选”列只显示官方当选标记图片，不根据票数自行推断。选举概况统一显示选举人数、投票人数、投票率、有效票、无效票、有效率、候选人数和当选人数；统计范围分为全部地区（含金门、马祖）、县市和具体选区／乡镇市区。议员按全国／县市／议员选区三级切换；台湾地区领导人、县市长、乡镇市区长按全国／县市／乡镇市区三级切换。标题精确指出年份、范围和选举类别，候选人结果窗口也可以直接进入对应地区概况。涉及区域、平地少数民族、山地少数民族等不同选举身份时，关键指标按各类别的选举记录加总，投票率按合计投票人数除以合计选举人数计算；因选民可能同时具有不同身份，**该合计不是不重复的自然人计数**。可视化概览继续分别显示各类选区，不混用不同类别的分母。2022年县市长选举已从中选会原始 `elprof.csv` 补齐21县市366个乡镇市区的选举人数、投票人数、有效票、无效票及投票率／有效率，并以 `mayorTownNames` 将原始繁体乡镇名称对应至地图简体名称。嘉义市2022年12月18日重行选举的东区、西区没有包含在原11月26日资料档中，仅保留逐区实际有效票，不推算其投票人数等指标。1996—2024年台湾地区领导人选举在乡镇市区层级仍仅使用已验证的候选人有效票；缺乏完整可靠投票统计时如实显示缺值。2022年地方选举使用已核验的逐选区投票统计；历届台湾地区领导人选举已补齐2012、2016、2020及2024年每届22个县市的选举人数、投票人数及按有效票核对的无效票和比率。2012—2020资料来自votetw.com逐县市选举统计并与全国合计核对，2024资料来自中选会委托报告表1-6（`history-presidential-turnout.js`记录链接）；2024年度原始县市合计与原有全台投票总数有1票差异，均忠实保留。尚未获得可靠县市投票统计的1996—2008年保留缺值，不将有效票当作投票人数。县市长结果可从县市层级下钻到乡镇市区得票分布，乡镇市区候选人表仍以全县市官方结果标记最终当选人。

主图、席次徽章、结果表和导出使用同一数据。SVG/PNG文件名包含年份、类别、范围和指标；历史CSV同时保留规范名称与官方原始名称。

**2026-11-14乡镇数据逐项复核：** 2022年共1,548组县市长／议员／乡镇市区长分乡镇市区有效票汇总，其中1,546组与中选会 `elprof.csv` 完全一致；7,291条候选人分乡镇市区得票记录中，7,281条与中选会 `elctks.csv` 逐条相符，均无错位／票数不一致。未在该原始档内的10条为嘉义市2022年12月18日市长重行选举东区、西区各5位候选人，分别加总42,637票、51,176票，合计93,813票，与嘉义市选举委员会全市公告一致。政大2022乡镇市长选举汇总有效票数3,109,582票，与中选会D1类别及网站对应类别核对。审计脚本见 `scripts/audit_history_2022_sources.py`；官方乡镇投票率补全脚本及CI见 `scripts/enrich_history_2022_town_profiles.py` 和 `.github/workflows/history-town-profiles.yml`。这里只校正统计关联和缺值，**不改写已核实的候选人得票数字**。

历史数据整理自台湾地区选举事务主管机构公开资料，经 [taiwanvotes.tw](https://www.taiwanvotes.tw/download/) 整理，并参考政治大学历届公职人员选举资料。网页左侧顶部“关于本站”统一列出数据来源，不在各结果面板和导出图片中重复显示。运行时快照采用版本2实体结构，包含选举、选举区、候选记录和来源校验信息。授权及官方公告见 `THIRD_PARTY_NOTICES.md`、`sources/history-2022-manifest.json`及审计资料。4条妇保当选标记补正在独立2022元数据中留有记录，原始906条当选标记保留，补正后910条。

### 历史趋势
历史数据新增“历史趋势”视图，按选举类别、票种、年份区间、当届/统一现行县市口径与政党筛选，生成得票率、得票数、当选席次、席次占比、排名、投票参与、候选人结构及字段覆盖率图。县市版图矩阵显示实际席次领先政党或当地得票领先政党，可点击进入对应届次。两届变化图按现行县市统一口径汇总原始票数；历史县市口径提供明细对照，不用现行地图伪装历史边界。2008年前不分区席次计算票与独立政党票分段绘制，不计算跨制度变化；1994年不完整议员数据不填零。图表支持 SVG、PNG 与统计 CSV 导出。选区编号变化不作为跨届地理匹配依据；同名乡镇仍可能有历史边界变化。2026年仅在正式结果发布门槛满足后纳入。

历史趋势的默认显示以左侧历史选举数据为筛选来源：选举类别、票种、县市、层级、选区/乡镇焦点、显示内容及指定候选人或政党实时同步。左侧年份是截止届次，趋势区仅保留起始届次与当前图表导出；不再同时展示无关的概况图表。领先数量按地图层级明确标为“领先县市数”或“领先乡镇市区数”，并与正式当选席次区分；领导人、县市长和乡镇市区长历史趋势另外绘制“候选人票得票率（按所属政党汇总）”，即各党候选人总票数占该范围有效票的比例，最高票候选人得票率仍按所选范围有效票加权计算。得票率折线仅在该党当届有参选记录时绘制，缺席届次留空并断线，已参选但得票为零则保留零值。数据点悬停提示候选人姓名、政党与该范围得票率；同届不同的无党籍（连署）候选人按该类别合并绘制，悬停逐人列示。历史县市名称不自动合并，不能核实同一选区范围时保留缺值。

历史趋势默认勾选所有可用届次，支持逐届复选、全选与清空；左侧年份用于当前地图和选区参照，不再限制趋势截止届次。席次图采用整数刻度、柱顶合计及逐席半圆图；堆叠柱内标出各政党席次，过窄的色块以引线标在柱旁。全部地区选择“全部类型”时，立法机构席次包含区域、少数民族、不分区及旧制侨选，逐届对账161、164、225（1998—2004）、113（2008起）席，同时显示不分区票种的政党得票率；选择“区域”时只显示区域民代的当选席次和该票种得票率，县市范围仅计该县市区域席次。选择“平地少数民族”“山地少数民族”或“不分区”时，全部地区显示该票种的正式当选席次与得票率，具体县市只显示得票率，不将全部地区的席次分摊到县市。县市议员趋势遵循同一范围规则：全部地区可查看各票种席次和得票率；具体县市的区域议员显示当地席次和得票率，少数民族议员只显示得票率。2008年前名单席次使用各党推荐候选人票汇总作为得票率分母，2008年起使用独立政党票，两段趋势不相连。

半圆席次图新增过半门槛标线（总席次除以2向下取整加1）、单一届次/总席次标注及党徽图例。民进党在左、国民党在右，台湾团结联盟、台湾基进靠左，新党、亲民党靠右，其余及无党籍居中；仅作视觉分组，不表示实际结盟。导出图内嵌党徽资源。
